### 🛡️ Phishing URL Detection using CNN-BiLSTM
> Deep learning model that detects phishing URLs with near-human accuracy

- 🧠 Fused **character-level CNN-BiLSTM** with 12 structural URL features
- 📊 Trained on **339,723 URLs** — balanced phishing and legitimate samples
- ✅ Achieved **97.75% accuracy** and **0.9980 ROC-AUC**
- 📈 Outperformed Random Forest (91.27%) and XGBoost (91.59%) **by 6+ points**
- 🌐 Deployed as a **Streamlit web app** for real-time predictions

**Tech:** Python · TensorFlow/Keras · Scikit-learn · XGBoost · Streamlit
